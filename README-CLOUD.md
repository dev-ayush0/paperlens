# PaperLens Cloud Deployment

PaperLens is a student-focused research paper discovery and reading MVP.

Cloud build:
- Parallel search across arXiv, PubMed Central, DOAJ and Project Gutenberg
- Strict relevance filtering
- ResearchGate direct-search handoff without scraping
- Saved papers, tags, reading history and annotations in the browser
- Optional Claude summaries through ANTHROPIC_API_KEY
- Railway-ready Docker deployment

The current MVP keeps library data browser-local. Account-based cross-device sync is a future backend layer.
